# PaeScape Issues

This repository is the public issue tracker for PaeScape.

The game client's **Report a Bug** panel opens `bug_report.yml` here and prefills the description and sanitized diagnostics. Source code and pull requests remain in [Paepay/tsps](https://github.com/Paepay/tsps) and [Paepay/PaeScape_Realms](https://github.com/Paepay/PaeScape_Realms).
